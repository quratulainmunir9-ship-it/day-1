## 📚 Topics Practiced

### 1. Profit Calculation

```python
sales = 15000
expenses = 5400
profit = sales - expenses
print(profit)
```

**Real-world use:** Calculate business profit by subtracting expenses from sales revenue.

### 2. Inventory Management

```python
stock = 3
minimum_stock = 5

if stock < minimum_stock:
    print("Restock needed")
else:
    print("Stock is enough")
```

**Real-world use:** Identify products that need restocking.

### 3. Conditional Logic

Practiced classifying stock levels, temperature categories, and student pass/fail results using conditions and logical operators.

### 4. Sales Analysis Using Loops

```python
sales = [1200, 2500, 1800, 3000]
total = 0

for sale in sales:
    total = total + sale

print(total)
```

**Real-world use:** Calculate total revenue from a list of sales transactions.

### 5. Filtering Sales

Practiced filtering sales greater than Rs. 1,000 and calculating their total using `for` loops and `if` conditions.

### 6. Finding Highest and Lowest Sales

Practiced finding maximum and minimum sales without using Python's built-in `max()` and `min()` functions.

### 7. Average and Count

Practiced using accumulator and counter variables to work with sales data. I am continuing to improve the logic for calculating averages of filtered values.
